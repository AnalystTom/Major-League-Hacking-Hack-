From backlog to working agent

  1. Paste what you saved

    X posts (including Articles), YouTube videos and talks, and Substack posts, one per line. No account linking.

  2. Get a skill for each one

    Each item becomes a SKILL.md that uses only what the source says and links back to the original post or video.

  3. Watch the short

    Items with one clear idea also get a short narrated clip. A separate reviewer model checks it against the source before it's published.

  4. Drop it where your agent looks

    Pick Claude Code, Codex, Cursor or Hermes. Resurface shows the exact file path for that agent, and you copy or download the skill.
