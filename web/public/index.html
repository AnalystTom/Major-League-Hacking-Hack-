Get started

From backlog to working agent

  1. Connect what you've saved

    X bookmarks, YouTube playlists, GitHub stars, newsletters and conference talks. Paste single links too.

  2. Watch a short for each one

    Every item becomes a 30-second short of the part worth keeping. Copy it, or send it straight to your agents.

  3. Check it against today's docs

    Before anything is installed, Resurface pulls the linked repo, release notes and open issues, so a year-old tip doesn't ship a deprecated flag.

  4. Install it where your agent looks

    Skills, rules and AGENTS.md sections land in your repo as a reviewable diff, each one linked back to the post or video it came from.
